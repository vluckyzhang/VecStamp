矢印 VecStamp v1.2.2 —— クイックスタート
==========================================

インストーラーは中国語表示です。メニューでは 1 = インストール / 更新、2 = アンインストール。
インストール後、「矢印」タブの「关于」（矢印について）グループの言語メニューで「日本語」を選ぶと、すぐに日本語になります。

【Windows · PowerPoint】
1. フォルダー全体を展開し、PowerPoint のウィンドウをすべて閉じます。
2. 「安装或卸载-Windows.bat」をダブルクリックし、1 を入力して Enter。
   初回はお使いの PowerPoint でソースからアドインを作成します。確認が表示されたら Y を入力してください
   （「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」を一時的に有効にし、完了後に元に戻します）。
3. PowerPoint を開くと、「表示」の右に「矢印」タブがあります。

【macOS · PowerPoint for Mac】
1. まず dist/VecStamp.ppam を用意します（Windows でインストーラーのメニュー 4 で作成、または docs/DEVELOPMENT.md の手順で Mac 上で作成）。
2. PowerPoint を終了し、「安装或卸载-macOS.command」をダブルクリック（開発元を検証できない場合は右クリック → 開く）して 1 を入力。
3. PowerPoint で：ツール → PowerPoint アドイン… → + → VecStamp.ppam → OK。

【Linux · LibreOffice Impress / Draw】
1. LibreOffice を閉じます。
2. ターミナルで bash 安装或卸载-Linux.sh を実行し、1 を入力（sudo 不要）。
3. Impress または Draw を開くと、「矢印」メニューとツールバーが表示されます。
   他の OS の LibreOffice でも dist/VecStamp-LibreOffice.oxt をダブルクリックしてインストールできます。

【アンインストール】インストーラーをもう一度実行し、2 を入力します。

【使い方】図形を選択 → 「エクスポート」または EMF / EMZ / SVG / PDF / VSDX / PNG をクリック。
背景は「背景」メニューで選びます（透明 / 白 / ベージュ / 方眼 / ユーザー設定の色。色パネルは「ユーザー設定の色」の中）。
PNG 解像度（最大 3000 DPI）や VSDX ネイティブ図形などは「エクスポート設定」で設定します。
エクスポート中は進行状況ウィンドウに割合と現在の処理が表示され、Esc（macOS では「キャンセル」）で中止できます。
詳しくは README.ja.md とリボンの「使い方」をご覧ください。問題があれば「フィードバック」（メールまたは GitHub Issue）からどうぞ。

矢印はずっと無料・オープンソースです。気に入ったら「作者を支援」から作者にコーヒーをごちそうしていただけるとうれしいです（任意）。
