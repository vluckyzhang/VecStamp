選取即印

PowerPoint 裡的圖形，一鍵匯出 EMF、SVG、PDF、Visio 等向量格式

論文插圖、標書配圖、技術文件：在投影片裡畫好的圖，選取後點一下，就能得到放大、列印都不失真的向量檔案。

下載 v1.2.2 檢視原始碼

適用於 Windows 和 macOS 版 PowerPoint（2013 及以上）、Linux 版 LibreOffice。永久免費，MIT 授權開源，離線可用。介面支援簡體中文、繁體中文、英文和日文。

使用步驟

  1. 選取圖形

    單個圖形、多個圖形或組合都可以；什麼都不選時，可以匯出目前投影片上的全部圖形。

  2. 點「匯出」

    在「矢印」選項卡上點大按鈕，或從下拉選單選擇格式。匯出時顯示進度百分比和目前步驟，按 Esc 可隨時取消。

  3. 插入你的文件

    把檔案插入 Word、LaTeX、Visio 或網頁。放大、列印、重新排版，線條和文字都保持清晰。

七種格式，按用途選

同一個按鈕，匯出到不同的地方。預設格式可以在功能區裡設定，下拉選單隨時切換。

格式適合用在說明
EMFWord / WPS 論文、報告插入後保持向量，按兩下可以取消組合繼續編輯。
EMZ郵件、網盤傳送壓縮過的 EMF，內容相同、體積更小，Office 可直接插入。
SVG網頁、Inkscape、Illustrator、Figma通用向量格式，瀏覽器可直接開啟；PowerPoint 2013 起均可匯出。
PDF期刊投稿、LaTeX、列印頁面大小就是圖形大小，不留白邊，字型隨檔案嵌入。
VSDX交給 Visio 繼續編輯由 Visio 原生形狀組成，文字可編輯，圓角保持為曲線；無法轉換的物件保留為向量圖片。
PNG只接受點陣圖的投稿系統150 / 300 / 600 DPI 或自訂，最高 3000 DPI，支援透明背景。
WMF只認舊格式的軟體相容性最好，但不支援透明和漸變，非必要不選。

背景也是向量

匯出時可以給圖形加上背景和邊界，七種格式都適用。向量格式裡的背景本身也是向量矩形和線條，不會變成一張底圖。

功能都在一個選項卡里

安裝後，PowerPoint 的「檢視」右側多出「矢印」選項卡：匯出、批次工具、背景、匯出設定和關於（含介面語言），都可以一鍵直達。

Linux 上用 LibreOffice

PowerPoint 沒有 Linux 版，矢印在 Linux 上以 LibreOffice Impress / Draw 擴充套件的形式提供：同樣的七種格式、五種背景、自訂解析度、逐頁匯出、Visio 原生形狀和四種介面語言。

這個擴充套件不依賴作業系統，Windows 和 macOS 上的 LibreOffice 也可以安裝。

安裝

下載後先完整解壓，再執行對應系統的安裝器，在選單裡選擇「安裝 / 更新」或「解除安裝」。

Windows

PowerPoint 2013 及以上，包括 2016、2019、2021、2024 和 Microsoft 365

  1. 儲存並關閉所有 PowerPoint 視窗
  2. 按兩下 安装或卸载-Windows.bat，輸入 1
  3. 開啟 PowerPoint，在「檢視」右側找到「矢印」

macOS 實驗性

PowerPoint for Mac 16.82 及以上

  1. 退出 PowerPoint
  2. 按兩下 安装或卸载-macOS.command，輸入 1；首次執行請在 Finder 中右鍵選擇「開啟」
  3. 在「工具 › PowerPoint 載入項」中新增 VecStamp.ppam，並選擇啟用宏

Linux

LibreOffice 6.4 及以上（Impress / Draw），無需 sudo

  1. 關閉 LibreOffice
  2. 在終端執行 bash 安装或卸载-Linux.sh，在選單中輸入 1
  3. 重新開啟 Impress，使用選單欄的「矢印」

也可以在 LibreOffice 的「工具 › 擴充套件管理器」中新增 VecStamp-LibreOffice.oxt。

只改目前使用者，敏感操作先徵得同意。安裝器不會修改系統安全設定：Windows 上需要臨時開啟的 VBA 工程訪問會先詢問並在完成後恢復，「受信任位置」只在你主動選擇時才新增；macOS 不會移除隔離屬性；Linux 以使用者模式安裝，拒絕以 root 執行。

常見問題

矢印收費嗎？會收集我的資料嗎？

不收費，永久開源免費，也沒有廣告。矢印在本機完成全部匯出，不聯網、不收集任何資料；只有你點選「意見回饋」或「專案首頁」時，才會開啟郵件程式或瀏覽器。

我的 PowerPoint 是 2016 / 2019，能匯出 SVG 嗎？

能。Microsoft 365 和 Office 2024（版本 2302 及以上）直接使用 PowerPoint 的 SVG 匯出；更早的 Windows 版本（2013 – 2021）會把圖形列印成 XPS，再由矢印內建的轉換指令碼產生 SVG，路徑、漸變、圖片和文字都會保留。轉換在背景進行，進度視窗顯示百分比，按 Esc 可隨時取消。整個過程在本機完成，不需要安裝其他軟體。

匯出的 VSDX 在 Visio 裡能編輯嗎？

能。矩形、圓角矩形、橢圓、箭頭、連線線、自由曲線和文字框都會轉成 Visio 原生形狀，1.2.2 起圓角和弧線保持為真正的曲線；填充、線條、箭頭和文字格式儘量保持一致，文字可以直接修改。圖表、SmartArt、藝術字等無法轉換的物件會作為 EMF 向量圖片保留在原位。

如果更想要一張整體的向量圖，可以在「匯出設定」中取消勾選「VSDX 原生形狀」。

介面可以切換成英文、繁體中文或日文嗎？

可以。在 PowerPoint 的「矢印」選項卡最右側「關於」組中開啟語言選單，選擇簡體中文、繁體中文、英文或日文，整個選項卡和之後的提示立即切換，不需要重新啟動。LibreOffice 版在「矢印 › 介面語言」中切換。

看不到「矢印」選項卡，或提示宏已被禁用？

在 PowerPoint 中開啟「檔案 › 選項 › 載入項」，管理「PowerPoint 載入項」，確認 VecStamp 已勾選。如果顯示宏被禁用，重新執行 Windows 安裝器並選擇 3，把載入項所在的資料夾新增為受信任位置；解除安裝時會一併移除。

匯出的 EMF 在別人電腦上字型變了？

EMF 和 SVG 記錄的是字型名稱，對方電腦缺少這個字型時會被替換。需要固定字型時請匯出 PDF（字型隨檔案嵌入），或在投稿前用 Inkscape、Illustrator 把文字轉為曲線。

3000 DPI 的 PNG 為什麼會提示檔案過大？

畫素數隨 DPI 的平方增長：一張 10 × 6 英寸的圖在 3000 DPI 下有 5.4 億畫素。超過約 1.2 億畫素時矢印會先請你確認。論文插圖通常 600 – 1200 DPI 就足夠，需要更清晰時優先選擇向量格式。

遇到問題怎麼意見回饋？

在「矢印」選項卡點「意見回饋」，可以選擇發郵件或在 GitHub 提交 Issue；也可以直接寫信到 vluckyzhang@gmail.com，或 新增 Issue。附上 PowerPoint 版本號（「檔案 › 賬戶 › 關於 PowerPoint」）和出問題的檔案，會更快找到原因。
