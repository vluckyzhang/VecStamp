ダウンロード

選んで、押すだけ。

PowerPoint の図形を EMF・SVG・PDF・Visio などのベクター形式にワンクリックで

論文の図、提案書、技術文書に。スライドで描いた図を選んでクリックするだけで、拡大しても印刷しても劣化しないベクターファイルが手に入ります。

ダウンロード v1.2.2 ソースコード

Windows / macOS の PowerPoint（2013 以降）と Linux の LibreOffice に対応。ずっと無料、MIT ライセンスのオープンソースで、オフラインで動作します。表示言語は日本語・英語・中国語（簡体字 / 繁体字）。

使い方

  1. 図形を選ぶ

    1 つの図形でも、複数の図形やグループでも OK。何も選ばなければスライドのすべての図形をエクスポートできます。

  2. 「エクスポート」をクリック

    「矢印」タブの大きなボタンをクリックするか、メニューから形式を選びます。エクスポート中は割合と現在の処理が表示され、Esc キーでいつでも中止できます。

  3. 文書に挿入

    Word・LaTeX・Visio・Web ページに挿入しましょう。拡大・印刷・再レイアウトしても、線と文字はくっきりしたままです。

7 つの形式を用途に合わせて

ボタンは 1 つ、行き先はさまざま。既定の形式はリボンで設定でき、メニューからいつでも切り替えられます。

形式用途説明
EMFWord / WPS の論文・レポート挿入後もベクターのまま。ダブルクリックでグループを解除して編集できます。
EMZメール、クラウドストレージ圧縮した EMF。内容は同じでサイズが小さく、Office にそのまま挿入できます。
SVGWeb、Inkscape、Illustrator、Figma汎用のベクター形式で、ブラウザーで直接開けます。PowerPoint 2013 以降ならエクスポート可能。
PDF学術誌への投稿、LaTeX、印刷ページは図形と同じ大きさで余白なし。フォントも埋め込まれます。
VSDXVisio での編集Visio のネイティブ図形で、文字は編集でき、角丸も曲線のまま。変換できないオブジェクトはベクター画像として残ります。
PNGビットマップしか受け付けない投稿システム150 / 300 / 600 DPI またはユーザー設定（最大 3000 DPI）。透明背景に対応。
WMF古い形式しか読めないソフト互換性は最も高いものの、透明とグラデーションには非対応。必要なときだけ。

エクスポート時に背景と余白を付けられます（7 形式すべて）。ベクター形式では背景自体もベクターの四角形と線で、画像にはなりません。

すべての機能を 1 つのタブに

インストールすると、PowerPoint の「表示」の右に「矢印」タブが追加されます。エクスポート、一括処理、背景、エクスポート設定、「矢印について」（言語メニューを含む）にワンクリックでアクセスできます。

Linux では LibreOffice で

PowerPoint には Linux 版がないため、Linux では LibreOffice Impress / Draw の拡張機能として提供しています。同じ 7 形式、5 種類の背景、ユーザー設定の解像度、スライドごとのエクスポート、Visio ネイティブ図形、4 つの表示言語に対応しています。

この拡張機能は OS に依存せず、Windows や macOS の LibreOffice にもインストールできます。

インストール

ダウンロードしたら、まずすべて展開してから、お使いの OS のインストーラーを実行し、メニューで 1（インストール / 更新）または 2（アンインストール）を選びます（メニューは中国語です）。

Windows

PowerPoint 2013 以降（2016、2019、2021、2024、Microsoft 365 を含む）

  1. PowerPoint のウィンドウをすべて保存して閉じる
  2. 安装或卸载-Windows.bat をダブルクリックし、メニューで次の番号を入力： 1
  3. PowerPoint を開くと「表示」の右に「矢印」タブがある

macOS 試験的

PowerPoint for Mac 16.82 以降

  1. PowerPoint を終了する
  2. 安装或卸载-macOS.command をダブルクリックし、メニューで次の番号を入力： 1（初回は Finder で右クリックして「開く」を選ぶ）
  3. 「ツール › PowerPoint アドイン」で VecStamp.ppam を追加し、マクロを有効にする

Linux

LibreOffice 6.4 以降（Impress / Draw）、sudo 不要

  1. LibreOffice を閉じる
  2. ターミナルで bash 安装或卸载-Linux.sh を実行し、メニューで次の番号を入力： 1
  3. Impress を開き直し、メニューバーの「矢印」を使う

LibreOffice の「ツール › 拡張機能マネージャー」で VecStamp-LibreOffice.oxt を追加することもできます。

変更は現在のユーザーだけ。重要な操作は先に確認します。インストーラーはシステムのセキュリティ設定を変更しません。Windows で一時的に必要な VBA プロジェクトへのアクセスは事前に確認し、完了後に元に戻します。「信頼できる場所」は自分で選んだときだけ追加します。macOS では検疫属性を削除しません。Linux ではユーザーモードでインストールし、root での実行は拒否します。

よくある質問

矢印は有料ですか？データを収集しますか？

いいえ。ずっと無料・オープンソースで、広告もありません。エクスポートはすべてお使いのパソコン上で行い、ネットに接続することもデータを収集することもありません。「フィードバック」や「プロジェクトページ」をクリックしたときだけ、メールソフトやブラウザーを開きます。

PowerPoint 2016 / 2019 でも SVG をエクスポートできますか？

はい。Microsoft 365 と Office 2024（バージョン 2302 以降）は PowerPoint 自身の SVG エクスポートを使います。それより前の Windows 版（2013～2021）では図形を XPS に印刷し、矢印に内蔵の変換スクリプトで SVG を作成します。パス、グラデーション、画像、文字は保持されます。変換はバックグラウンドで行われ、進行状況ウィンドウに割合が表示され、Esc でいつでも中止できます。処理はすべてお使いのパソコンで行い、ほかのソフトは不要です。

エクスポートした VSDX は Visio で編集できますか？

はい。四角形、角丸四角形、楕円、矢印、コネクタ、フリーフォーム、テキストボックスは Visio のネイティブ図形に変換され、1.2.2 からは角丸や円弧も本物の曲線のままです。塗りつぶし、線、矢印、文字の書式もできるだけ保持し、文字はそのまま編集できます。グラフ、SmartArt、ワードアートなど変換できないものは EMF ベクター画像として元の位置に残ります。

図全体を 1 枚のベクター画像にしたい場合は、エクスポート設定で「VSDX ネイティブ図形」のチェックを外してください。

日本語で使えますか？

はい。PowerPoint の「矢印」タブの右端、「关于」（矢印について）グループの言語メニュー（「简体中文」と表示）で「日本語」を選ぶと、タブ全体と以降のメッセージがすぐに日本語になります。再起動は不要です。LibreOffice 版は「矢印 › 表示言語」で切り替えます。

「矢印」タブが表示されない、またはマクロが無効と表示される

PowerPoint で「ファイル › オプション › アドイン」を開き、「PowerPoint アドイン」を管理して VecStamp にチェックが入っているか確認してください。マクロが無効と表示される場合は、Windows インストーラーをもう一度実行して 3 を選び、アドインのフォルダーを信頼できる場所に追加します（アンインストール時に一緒に削除されます）。

エクスポートした EMF のフォントが他のパソコンで変わる

EMF と SVG はフォント名を記録しているため、相手のパソコンにそのフォントがないと置き換えられます。フォントを固定したい場合は PDF（フォントを埋め込み）でエクスポートするか、投稿前に Inkscape や Illustrator で文字をアウトライン化してください。

3000 DPI の PNG でサイズの警告が出るのはなぜ？

ピクセル数は DPI の 2 乗で増えます。10 × 6 インチの図は 3000 DPI で 5 億 4000 万ピクセルです。約 1 億 2000 万ピクセルを超える場合は確認を求めます。論文の図なら通常 600～1200 DPI で十分で、さらに高精細が必要ならベクター形式をおすすめします。

問題を報告するには？

「矢印」タブの「フィードバック」から、メールを送るか GitHub で Issue を作成できます。直接 vluckyzhang@gmail.com 宛てにメールするか、 新しい Issue を作成してください。PowerPoint のバージョン（「ファイル › アカウント › PowerPoint のバージョン情報」）と問題のファイルを添えていただくと、原因を早く特定できます。
