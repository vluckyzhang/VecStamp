Select. Stamp. Vector.

Export PowerPoint shapes to EMF, SVG, PDF, Visio and more – in one click

Paper figures, proposals, technical documents: select a diagram you drew on a slide, click once, and get a vector file that stays sharp however much you zoom or print it.

Download v1.2.2 Source code

For PowerPoint on Windows and macOS (2013 or later) and LibreOffice on Linux. Free forever, MIT-licensed open source, works offline. Interface in English, Japanese, Simplified and Traditional Chinese.

How it works

  1. Select shapes

    One shape, several shapes or a group; with nothing selected you can export every shape on the slide.

  2. Click Export

    Click the large button on the VecStamp tab, or pick a format from its menu. A progress window shows the percentage and the current step; press Esc to cancel at any time.

  3. Use it anywhere

    Insert the file into Word, LaTeX, Visio or a web page. Zoom, print, re-typeset – lines and text stay sharp.

SVG export no longer hangs
The SVG conversion for older PowerPoint versions now runs in the background with live progress; Esc stops it at once, and after 180 seconds it stops by itself and offers alternatives.
Rounded corners stay curved
Rounded rectangles, round-corner arrows, clouds, arcs and 173 more preset shapes are computed from the standard formulas; corners become Visio elliptical arcs instead of polygons.
Progress with percentage
The progress window shows the percentage, the current file or slide, the current step and the elapsed time – cancellable on Windows, macOS and LibreOffice.
Colour panel in the Background menu
The custom colour panel now lives in the Background menu, and a square in front of "Background" previews the current background. When PowerPoint's colour dialog is unavailable, VecStamp's own colour panel takes over.
Four interface languages
English, Japanese, Simplified and Traditional Chinese – switch instantly in the language menu of the About group, no restart needed.
Multilingual docs and website
The README and this website are available in four languages, too.

Everything on one ribbon tab

After installing, PowerPoint gets a VecStamp tab next to View: export, batch tools, background, export settings and About (with the language menu) are one click away.

LibreOffice on Linux

There is no PowerPoint for Linux, so on Linux VecStamp is a LibreOffice Impress / Draw extension with the same seven formats, five backgrounds, custom resolution, slide-by-slide export, native Visio shapes and four interface languages.

The extension is platform-independent – LibreOffice on Windows and macOS can install it, too.

Install

After downloading, extract everything first, then run the installer for your system and choose 1 (install / update) or 2 (uninstall) in its menu – the installer menus are in Chinese.

Windows

PowerPoint 2013 or later, including 2016, 2019, 2021, 2024 and Microsoft 365

  1. Save and close all PowerPoint windows
  2. Double-click 安装或卸载-Windows.bat and enter 1
  3. Open PowerPoint – the 矢印 / VecStamp tab is right of View

macOS experimental

PowerPoint for Mac 16.82 or later

  1. Quit PowerPoint
  2. Double-click 安装或卸载-macOS.command and enter 1; the first time, right-click it in Finder and choose Open
  3. In Tools › PowerPoint Add-ins, add VecStamp.ppam and enable macros

Linux

LibreOffice 6.4 or later (Impress / Draw), no sudo needed

  1. Close LibreOffice
  2. In a terminal, run bash 安装或卸载-Linux.sh and enter 1
  3. Open Impress again and use the VecStamp menu

You can also add VecStamp-LibreOffice.oxt in LibreOffice under Tools › Extension Manager.

Current user only; nothing sensitive without your consent. The installers never change system security settings: on Windows the temporary VBA project access is asked for first and restored afterwards, and a trusted location is only added when you choose it; on macOS the quarantine attribute is not removed; on Linux the extension is installed in user mode and running as root is refused.

FAQ

Does VecStamp cost anything? Does it collect data?

No. It is free and open source forever, without ads. Everything is exported on your computer – no network access, no data collection; only Feedback and Project page open your mail program or browser when you click them.

I have PowerPoint 2016 / 2019 – can I export SVG?

Yes. Microsoft 365 and Office 2024 (version 2302 or later) use PowerPoint's own SVG export; older Windows versions (2013–2021) print the shapes to XPS and VecStamp's built-in converter turns that into SVG, keeping paths, gradients, pictures and text. The conversion runs in the background with a percentage, and Esc cancels it at any time. Everything happens on your computer – nothing else to install.

Can I edit the exported VSDX in Visio?

Yes. Rectangles, rounded rectangles, ellipses, arrows, connectors, freeforms and text boxes become native Visio shapes, and since 1.2.2 rounded corners and arcs stay true curves; fills, lines, arrowheads and text formatting are kept as closely as possible, and the text is editable. Charts, SmartArt, WordArt and other objects that cannot be converted stay in place as EMF vector pictures.

If you prefer one picture for the whole drawing, clear "VSDX native shapes" in the export settings.

Can I use VecStamp in English?

Yes. Open the language menu in the About group at the right end of the 矢印 / VecStamp tab (it shows "简体中文") and choose English – the whole tab and all messages switch at once, no restart needed. In LibreOffice use VecStamp › Language.

No VecStamp tab, or macros are disabled?

In PowerPoint open File › Options › Add-ins, manage PowerPoint Add-ins and make sure VecStamp is ticked. If macros are disabled, run the Windows installer again and choose 3 to add the add-in folder as a trusted location; it is removed again when uninstalling.

Fonts change when the EMF is opened on another computer?

EMF and SVG store font names; a computer without the font substitutes another one. Export PDF when the fonts must not change (they are embedded), or convert the text to outlines with Inkscape or Illustrator before submitting.

Why does a 3000 DPI PNG trigger a size warning?

The pixel count grows with the square of the DPI: a 10 × 6 inch figure at 3000 DPI has 540 million pixels. VecStamp asks before creating more than about 120 megapixels. 600–1200 DPI is usually plenty for papers – prefer a vector format when you need more.

How do I report a problem?

Click Feedback on the VecStamp tab to send an e-mail or open a GitHub issue; you can also write to vluckyzhang@gmail.com, or open a new issue. Please include your PowerPoint version (File › Account › About PowerPoint) and the file in question – that helps find the cause faster.
