矢印 VecStamp v1.2.1 —— 快速开始
====================================

【Windows · PowerPoint】
1. 把整个文件夹完整解压，关闭所有 PowerPoint 窗口。
2. 双击「安装或卸载-Windows.bat」，输入 1 回车。
   第一次安装会用你电脑上的 PowerPoint 从源码生成加载项，按提示输入 Y 同意即可
   （会临时开启「信任对 VBA 工程对象模型的访问」，完成后自动恢复）。
3. 打开 PowerPoint，在「视图」右侧找到「矢印」选项卡。

【macOS · PowerPoint for Mac】
1. 先准备 dist/VecStamp.ppam（在 Windows 上用安装器菜单 4 生成，或按 docs/DEVELOPMENT.md 在 Mac 上生成）。
2. 退出 PowerPoint，双击「安装或卸载-macOS.command」（若提示无法验证开发者：右键 → 打开），输入 1。
3. 在 PowerPoint 中：工具 → PowerPoint 加载项… → + → 选择 VecStamp.ppam → 确定。

【Linux · LibreOffice Impress / Draw】
1. 关闭 LibreOffice。
2. 在终端运行：bash 安装或卸载-Linux.sh ，输入 1（不需要 sudo）。
3. 打开 Impress 或 Draw，菜单栏出现「矢印」菜单和「矢印」工具栏。
   其他系统的 LibreOffice 也可以直接双击 dist/VecStamp-LibreOffice.oxt 安装。

【卸载】再次运行对应的安装器，输入 2。

【使用】选中图形 → 点「导出」或 EMF / EMZ / SVG / PDF / VSDX / PNG。
背景（透明 / 白色 / 米色 / 网格 / 自定义颜色，「背景颜色」面板与 PowerPoint 相同）、
PNG 分辨率（最高 3000 DPI）、VSDX 原生形状等在「背景」和「导出设置」中设置。
导出时会显示进度窗口，Windows 上按 Esc 可取消。
更多说明见 README.md 和功能区「关于 → 使用说明」；遇到问题点「反馈」（邮件或 GitHub Issue）。
