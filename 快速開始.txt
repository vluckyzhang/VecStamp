矢印 VecStamp v1.2.2 —— 快速開始
====================================

【Windows · PowerPoint】
1. 把整個資料夾完整解壓縮，關閉所有 PowerPoint 視窗。
2. 按兩下「安装或卸载-Windows.bat」，輸入 1 按 Enter。
   第一次安裝會用你電腦上的 PowerPoint 從原始碼產生載入項，按提示輸入 Y 同意即可
   （會臨時開啟「信任對 VBA 工程物件模型的訪問」，完成後自動恢復）。
3. 開啟 PowerPoint，在「檢視」右側找到「矢印」選項卡。

【macOS · PowerPoint for Mac】
1. 先準備 dist/VecStamp.ppam（在 Windows 上用安裝器選單 4 產生，或按 docs/DEVELOPMENT.md 在 Mac 上產生）。
2. 退出 PowerPoint，按兩下「安装或卸载-macOS.command」（若提示無法驗證開發者：右鍵 → 開啟），輸入 1。
3. 在 PowerPoint 中：工具 → PowerPoint 載入項… → + → 選擇 VecStamp.ppam → 確定。

【Linux · LibreOffice Impress / Draw】
1. 關閉 LibreOffice。
2. 在終端執行：bash 安装或卸载-Linux.sh ，輸入 1（不需要 sudo）。
3. 開啟 Impress 或 Draw，選單欄出現「矢印」選單和「矢印」工具列。
   其他系統的 LibreOffice 也可以直接按兩下 dist/VecStamp-LibreOffice.oxt 安裝。

【解除安裝】再次執行對應的安裝器，輸入 2。

【使用】選取圖形 → 點「匯出」或 EMF / EMZ / SVG / PDF / VSDX / PNG。
背景在「背景」選單中選擇（透明 / 白色 / 米色 / 格線 / 自訂顏色，顏色面板就在「自訂顏色」裡），
PNG 解析度（最高 3000 DPI）、VSDX 原生形狀等在「匯出設定」中設定。
匯出時會顯示進度視窗（百分比和目前步驟），按 Esc（macOS 點「取消」）可取消。
介面語言：在「關於」組的語言選單中切換簡體中文 / 繁體中文 / English / 日本語，立即生效。
更多說明見 README.md 和功能區「關於 → 使用說明」；遇到問題點「意見回饋」（郵件或 GitHub Issue）。

矢印永久開源免費。覺得好用的話，可以在「關於 → 贊助作者」掃碼請作者喝杯咖啡（完全自願）。
